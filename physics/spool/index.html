The idea to look for

Look at the point touching the table.

The string pulls to the right in both experiments. With rolling without slipping, the rim point touching the table is instantaneously at rest. Consider the turning effect of the pull about this contact point P.

String on top: a larger turning effect

The horizontal line of the pull is R + r above P. Its turning effect is clockwise: the spool accelerates to the right.

String underneath: still above the table

The string is below the axle centre, but its pull is R − r above P. This distance is still positive, so the turning effect is still clockwise.

Same direction, different acceleration. For equal force, mass and inertia, the top-string case accelerates more. The inner string unwinds in the top case and winds back onto the axle in the bottom case; the animated string end moves consistently with that winding.

atop = F (1 + r/R) / [m + I/R²]
abottom = F (1 − r/R) / [m + I/R²]

The contact point is an instantaneous centre of motion, not a permanent hinge. A different part of the rim touches the table as the spool rolls. Static friction provides the force needed for rolling; it need not point opposite the motion. Turn on the force arrows to inspect its calculated direction.

Change the experiment

Changing a physics setting resets the trial. The inner radius stays smaller than the outer radius. Both cases use the same settings. The table has enough grip for rolling without slipping at every offered setting.

For teachers: model, questions and keyboard controls

Try this sequence. Start with the string on top. Ask for a prediction and use “Pull for 2 seconds.” Switch to underneath, predict again, then run it. Finally choose “Compare both” for the same force and elapsed time. Reveal the contact-point explanation only after pupils have described what they saw.

Questions. Is the lower string actually pulling below the table contact? Which arrangement has the larger lever arm? What happens as r gets closer to R? Why does a larger mass accelerate less for the same force? Does static friction always oppose the spool’s motion?

Scope. These pulls are horizontal. An upward-angled pull can produce different behaviour; this simulation does not model angled pulling, slipping, lift-off, string stretch, or changing axle radius as string layers accumulate.

Physics. Translation and rotation obey F + f = ma, −σrF + Rf = Iα, and α = −a/R, where σ = +1 for top and −1 for bottom. Thus f = ma − F. Work by the pull equals the increase in translational plus rotational kinetic energy. Ideal static friction does no work at the stationary contact point. The required grip coefficient |f|/(mg) is below 0.6 for all available settings.

Playback. Holding the button applies a constant force. Releasing it removes that force; the ideal spool coasts. “Pull for 2 seconds” starts a fresh trial and freezes it at exactly two simulated seconds, unless the finite free string runs out first. “Small pull” applies force for 0.05 simulated seconds. A reference mark on the ground makes translation visible. The camera stays fixed during the two-second trial, with the same scale in both cases. It follows if a longer pull goes beyond that view. Drag to orbit, or choose Side view.

Keyboard. Hold Space to pull; release to coast. P pauses/resumes, R resets, N gives a small pull. Keyboard shortcuts do not override form controls. A hidden tab or lost window focus pauses playback and releases the pull.
